🚚 Dispatch Plan
All quantities in PACKETS · Dynamic classification · 525 pkt cap/run · Branch freezer max 110kg
Dynamic fast mover logic: Items are classified Wed/Fri/Sat dynamically based on branch stock levels. Any item where a branch has <2 days of stock before the next dispatch automatically appears in Wed AM or Fri AM. No hardcoded list.
Slow movers (Saturday only): Items where stock lasts >3 days are only dispatched Saturday — pulling from factory freezer mid-week causes time loss. Saturday = full 7-day restock.
Quantities basis: Daily consumption rate × days to cover per branch. After daily sales uploads, switches to actual consumption since last dispatch.
525 pkt cap: If Saturday exceeds 525 pkts, system flags it and splits into 2 runs. Prioritise by lowest days-of-stock-remaining.
Urgent / ad-hoc dispatch: Log Factory→Branch or Branch→Branch in the Kitchen Inventory tab.

📦 Kitchen Inventory Tracker
Daily closing stock per branch · gram-level tracking · ceiling rounding to whole packets · Full audit trail
How inventory tracking works:
1. Enter closing stock — provide the closing stock for any branch on any day (in packets). This is your starting point.
2. Upload daily sales — upload yesterday's Item Wise + Addon XLSX for any branch. System reduces stock by what was sold (gram-level, rounded up to ceiling packets at EOD).
3. Record dispatch — after each Wed/Fri/Sat dispatch, confirm quantities sent. Factory stock decreases, branch stock increases.
4. Ad-hoc dispatch — log any urgent Factory→Branch or Branch→Branch transfer outside scheduled runs.
5. Discrepancy flag — if calculated closing stock goes negative, system flags it as ⚠ Stock Discrepancy for investigation.
Branch freezer limit: 110kg per branch. System warns before dispatch if limit would be exceeded.
